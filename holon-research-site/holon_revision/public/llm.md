## Questions

### What models can I run?

Anything from Huggingface that fits. We regularly test and optimize newly released models for Holon’s specific build. We preload Gemma 4 26B, Qwen 3.6 35B, Qwen 3.8 27B and GPT-OSS 20B out of the box.

Enterprise version runs Deepseek V4 Flash, Qwen 3.8 Flash Next, Qwen 3.5 122b a10b

### Do I need to set anything up beyond plugging it in and joining wifi?

No, obviously.

### Can I use other coding agents?

Yes. You can use any coding agent you want. We offer plugins for Codex, Opencode and Pi that let them use Holon’s model runtime.

### How is web search and deep research unlimited?

It’s self-hosted, on-device.

### Can I load multiple models at once?

Yes, if they fit.

### Are knowledge packs transferable across models?

Yes. Holon can schedule nightly rebuilds, which makes it seamless to use the same knowledge packs across models.
